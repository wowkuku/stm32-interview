# STM32 面试题精讲 · 可视化讲解网页

> 任何 AI / 人接手此目录，**先读完本文件再动代码**。每个 HTML 文件开头还有一段同源注释，内容与本文档一致。

## 1. 这是什么

李（深圳，25 届环境科学转嵌入式，尚硅谷六门已学完，正刷 STM32）会连续提出 STM32 问题。
每个问题被**改写成面试高频考法**，并做成**一个独立的、可离线打开的单页讲解网页**。

交付形态要求（李 2026-11-24 明确）：可直接打开的网页文件，含问题描述、思路解析、源码展示、关键要点。

## 3. 每个题目页的固定六块（顺序不许调换）

| 区块 | 内容 |
|---|---|
| ① 面试题干 | 把原始问题改写成面试官真会问的样子，含考察点与追问层 |
| ② 30 秒版答案 | 面试现场张口就来的那段，先给结论 |
| ③ 思路解析 | 讲"为什么"，配结构图 / 时序图 / 位域拆解器等内联 SVG 或交互件 |
| ④ 可运行源码 | 裸寄存器版 + 标准库版；能在 PC 上验证的给出**实跑输出** |
| ⑤ 关键要点 | 5 条以内，带编号，便于考前扫读 |
| ⑥ 追问与扣分点 | 面试官接着问什么、哪些回答减分、哪些动作加分 |

页尾固定一句"记忆锚"（一句话总结），便于复述。

## 4. 技术约定（硬约束）

1. **零依赖**：无 CDN、无框架、无外链字体。双击 HTML 即可离线打开，`file://` 下功能完整。
2. **共用资源不可拆**：所有页面共享 `assets/style.css` 与 `assets/app.js`，不要复制粘贴样式到单页。
3. **换主题只改 `:root` 变量**，不要在页面里硬编码颜色（内联 SVG 例外，需显式 `fill`）。
4. **代码块写法**：
   ```html
   <figure class="code">
     <figcaption><span class="fname">文件名</span><span class="note">说明</span><button class="copy" type="button">复制</button></figcaption>
     <pre><code class="lang-c">…HTML 特殊字符已转义…</code></pre>
   </figure>
   ```
   不需要着色的块（编译器输出、终端记录）用 `<code data-raw>`，可以让着色器跳过。
5. **引号**：正文中文引号照常用；代码块与属性内的引号必须是 ASCII 直引号。
6. **HTML 注释内禁止出现 `--`**（会破坏注释边界），分隔线一律用 `=`。
7. **新增题目页**：复制已有页 → 改名 `NN-英文短名.html` → 写六块 → 同步 `index.html` 的列表项与顶部计数。
8. **页内所有 `<h2 id>` 会自动进左侧目录**（`app.js` 从 `data-toc` 属性取标题文字）。

## 5. 事实口径

- 芯片：**STM32F103**（示例容量按 F103C8T6：64KB Flash / 20KB SRAM）；寄存器地址取自 **RM0008**。
- 库：标准外设库（SPL）为准，同时给裸寄存器写法（面试手写用）。
- **数字必须有来源**：PC 侧结论给 gcc 实跑输出；MCU 侧代码给 Keil AC5 / AC6 编译结果。
- F4 / H7 差异在页内单独标注，不混写。
- Keil 菜单字样标注"以你本机为准"（版本差异）。
