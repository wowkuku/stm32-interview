面试题干

面试官问

STM32 的 GPIO 有几种输出模式？推挽和开漏的本质区别在哪，什么时候必须用开漏？
请不依赖库函数，把 PA0 配置成推挽输出 50MHz，并说明 CRL 寄存器里那 4 位每一位的含义。

考察点：内部电路结构 → 电平能力 → 应用场景 → 寄存器位域 → 时钟使能这个必踩坑。
面试官真正想听的不是"背四种模式"，而是你能不能从电路推出什么时候该用哪个。

30 秒版答案

先给结论，再展开

推挽有上、下两个 MOS，能主动输出高和低，驱动能力强；开漏只有下管，只能拉低，高电平得靠外部上拉电阻——所以它天生适合电平转换、线与、I²C 这类双向总线。寄存器上每根脚在 CRL/CRH 里占 4 位：低 2 位 MODE 是速度/输入，高 2 位 CNF 是模式类型，PA0 配推挽 50MHz 就是写 0x3。

思路解析

3.1 从电路看区别：为什么"开漏只能拉低"

面试官问"本质区别"，答案不在寄存器里，在输出级只有几个 MOS 管这件事上。看下面这张图就够：

一句话抓住本质 推挽 = 有资格"说两种话"；开漏 = 只会"拉低"和"闭嘴"。凡是多个器件共用一根线（I²C、1-Wire、多主总线、中断线）的场景，必须用开漏——因为只有"拉低 / 放手"才能做线与而不烧管子。

3.2 CRL / CRH 的位域：4 位一个引脚

F1 系列没有"每脚一个寄存器"，而是 16 根脚挤在 32 位里：CRL 管 PA0~PA7，CRH 管 PA8~PA15（B/C/D/E 口同理）。每 4 位 = CNF[1:0] + MODE[1:0]。

位域拆解器 —— 改 CNF / MODE，看它到底变成什么模式

模式含义随 MODE 是否为 00 而整体翻转，这是最容易配错的地方，亲手拨一遍比背表管用。

3.3 四种输出模式对照

CNF模式高电平由谁给典型用途坑
00通用推挽 Out_PP内部 P-MOSLED、蜂鸣器、普通数字输出、SPI 单向两脚对推容易烧
01通用开漏 Out_OD外部上拉电平转换、线与、软件 I²C忘接上拉 → 永远读不到高
10复用推挽 AF_PP内部 P-MOSUSART_TX、SPI_SCK/MOSI、PWM 输出配成通用口 → 外设没波形
11复用开漏 AF_OD外部上拉硬件 I²C 的 SCL/SDA、SMBus忘接上拉 → 总线恒低
同一个 CNF，在输入模式下含义完全不同 当 MODE = 00 时：CNF=00 模拟输入（ADC 用）、01 浮空输入（复位默认值）、10 上拉/下拉输入（具体哪个由 ODR 位决定）、11 保留。所以"把脚配成输入"只有 MODE=00 是不够的，CNF 写错就会变成模拟或保留。

可运行源码

下面三段：裸寄存器版（不依赖任何库，面试手写就这个）、标准库版（工程里实际用的）、PC 侧位域验证（烧板子前先确认写的值对不对，已在本机实跑）。

烧板子之前，先在 PC 上把"该写哪 4 位"算清楚——这类错误在板子上只会表现为"没反应"，看不出原因。

看第二行 —— 这就是最常见的坑 想清 PA0 却只清低 2 位 &= ~(0x3 << 0)，CNF 里残留的 01 还在，结果 0x7 = 开漏而不是推挽。板子上的表现：LED 接法不变时"好像也能亮"，但换成推电流的负载就软了。清位掩码必须是 0xF。

关键要点（记这几条就够）

  • 先时钟后配置：RCC_APB2ENR 的对应位置 1 之前，写 CRL/CRH 全部无效——而且不报错，只是"没反应"。这是面试官最爱埋的雷。
  • 4 位一引脚，掩码 0xF：CRL 是 PA0~7 每脚 4 位（偏移 4*n）；CRH 是 PA8~15（偏移 4*(n-8)）。PA8 还在 CRL 里找——这是第二个雷。
  • MODE=00 时 CNF 完全换含义：输入不是"什么都不配"，CNF 决定模拟/浮空/上拉。上拉还是下拉看 ODR。
  • 推挽 vs 开漏只差"有没有上管"：有上管 → 可主动输出高，驱动强；无上管 → 只能拉低，靠外部上拉，换来线与与电平转换能力。
  • 复用 = 引脚让给片上外设：USART/SPI/TIM 输出必须配 AF_PP（I²C 是 AF_OD），配成通用口外设照样不动。

面试官会接着问什么

追问怎么答（一句到位）
为什么 I²C 必须开漏？多主多从共用两根线，靠线与仲裁：任何一方拉低总线就是低，谁都不许"强行输出高"。推挽会形成两管对灌，直接烧。
开漏输出高电平时有什么缺点？上升沿由 R×C 决定，上拉越大越慢。所以高速场合要减小上拉（功耗↑）或用有源上拉。
推挽能直接驱动 LED 吗？几毫安？能。单脚建议 ≤8mA，整片 VDD/VSS 合计有上限（F103 单脚 25mA 绝对最大值、总和 150mA）。驱动大电流要加三极管/MOS。
为什么输出用 BSRR 而不是 ODR？ODR 是"读-改-写"，多任务/中断里操作同一端口会互相覆盖；BSRR 单次写、硬件原子，且能同时置位/复位不同脚。
50MHz 是什么意思？是输出翻转速度档位，不是时钟频率。档位越高边沿越陡、EMI 越大，够用就行，别一律 50MHz。

扣分回答

  • "推挽输出高低电平，开漏输出低电平" —— 然后就停了，没提外部上拉和场景。
  • 配 GPIO 不提时钟使能，直接写 CRL。
  • 把 CNF 和 MODE 的位序记反（说低 2 位是 CNF）。
  • PA8 去 CRL 里配（忘了 CRH）。

加分动作

  • 主动说"清位要 &= ~(0xF << 4n)"，面试官会认为你真写过。
  • 补一句"上拉输入还是下拉输入由 ODR 决定"。
  • 补一句"BSRR 原子写，适合中断里点灯"。
一句话带走的记忆锚

上管决定"能不能说高"，下管决定"能不能说低"。推挽两个都有，所以能主动；开漏只有下管，所以只能拉低、剩下靠上拉——这就是它敢上总线的理由。
